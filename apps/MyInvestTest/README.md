# MyInvest20260601

这是一个用于辅助 A 股投资决策的 Codex 项目。项目目标不是让 AI 无脑荐股，而是把市场研究、主线判断、ETF/个股分析、仓位建议、操作建议和复盘沉淀成可审查、可追踪、可协同的工作流。

## 新电脑如何开始

1. 克隆项目到本地。
2. 先阅读 [项目记忆](docs/PROJECT_MEMORY.md)，了解已经确定的策略、规则和历史决议。
3. 阅读 [数据源与权限](docs/DATA_SOURCES.md)，确认本地数据权限配置。
4. 运行 `python scripts/project_check.py`，检查本地 `.env`、JSON 文件和研究产物命名状态。
5. 再阅读 [协作规则](docs/WORKFLOW.md) 和 [每日流程标准](docs/DAILY_PROCESS.md)，按固定流程继续工作。
6. 每次和 Codex 形成新的重要决议后，更新 `docs/PROJECT_MEMORY.md` 或对应研究文件。
7. 每次更新后提交 Git commit，保持多台电脑之间的上下文一致。

## 核心原则

- 研究成果先固化，再基于固化结果生成操作建议。
- 市场仓位、主线研究、ETF 研究、个股研究、组合分析、操作建议要分模块进行。
- 盘前执行检查只做执行门禁和盘中监控清单，不替代操作建议。
- Codex 给出的每个操作建议都必须能追溯到前置研究结论。
- 任何买入、加仓、减仓、卖出建议都必须包含理由、失效条件和复盘入口。
- 新结论不能覆盖旧结论，必须留下变更记录。

## 国证自由现金流全收益指数图

运行：

```bash
pip install -r requirements.txt
python scripts/plot_free_cash_flow_index.py
```

程序默认生成 `480092.CNI` 国证自由现金流全收益指数的研究入口页。首页只作为各项研究入口，每个历史研究沉淀为一个策略卡片；具体图表和回放放在独立研究页里。

当前策略卡片：

- 滚动 Log 回归通道：无未来函数的滚动通道研究，动态比较买入持有与通道回放收益
- ZigZag 高低拐点策略：按标准 ZigZag 规则确认高低拐点并做形态观察；页面默认对数 Y 轴，不默认勾选其他趋势线，显示 ZigZag 折线中点线、交点差距，并只用无未来函数的 20% 回撤买入策略和核心仓+机动仓策略展示收益回测和策略净值曲线

Log 回归通道研究页提供动态参数：

- 主曲线：`480092.CNI` 收盘价
- 中轨：每个交易日只用当日及以前的回看窗口数据，对 `log(close)` 做线性回归，再还原为点位
- 上下轨：中轨加减残差标准差倍数，默认 `±2.75σ`
- 回看年数：`1` 至 `10` 年，默认 `2` 年；图上始终显示全部历史数据，滑块只控制每天拟合轨道时向前取多少年历史
- 通道宽度：`1.00σ` 至 `3.00σ`，步长 `0.25σ`
- 当前默认参数：样本内表现较好的 `2年 / 2.75σ`；2016-04-01 至 2026-06-30 同口径回放中，买入持有年化约 `16.48%`，通道回放年化约 `20.77%`
- 滚动通道：每个交易日只使用当日及以前数据拟合当天轨道，收益回放不使用未来数据
- ZigZag 折线：默认阈值 `15%`，可用 `5%` 至 `40%` 阈值动态调整，并在段落端点显示本段涨跌幅；图中额外连接每段折线的中点作为辅助线；仅作为形态叠加参考，不参与通道回放收益计算
- 收益对比：同一窗口内动态比较买入持有收益和通道回放收益
- 通道回放口径：起始日持有指数，收盘价触及或高于上轨时卖出，触及或低于下轨时买入；不计交易成本、滑点和税费
- 页面头部：提供统一研究入口链接，便于后续把每次研究页挂到同一入口

输出文件在 `output/`：

- `index.html`：Web 服务默认入口页面，各项研究以策略卡片展示
- `480092_CNI_new_high_low.html`：Log 回归通道研究页
- `480092_CNI_zigzag_strategy.html`：ZigZag 高低拐点策略研究页
- `480092_CNI_daily.csv`：日线数据，含 `turning_high` 和 `turning_low` 标记列
- `480092_CNI_record_points.csv`：所有波段拐点记录点

为兼容旧浏览器路径，程序也会覆盖生成 `a_share_free_cash_flow_total_return.html` 和 `a_share_free_cash_flow_total_return.csv`。
